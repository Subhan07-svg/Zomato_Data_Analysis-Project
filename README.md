# Zomato Data Analysis Project Using Python

## 📌 Project Overview
This project focuses on analyzing Zomato restaurant data using Python. The main purpose is to understand restaurant types, customer votes, ratings, online ordering preferences, and approximate spending.

Exploratory Data Analysis (EDA) and data visualization are used to explore patterns in the dataset and answer important business questions.

## 🎯 Project Objective
The objectives of this project are:

- To identify the restaurant types customers order from most frequently.
- To analyze the number of votes received by different restaurant types.
- To understand restaurant rating patterns.
- To examine the approximate cost of ordering food for two people.
- To compare ratings for restaurants that accept and do not accept online orders.
- To identify restaurant types that may benefit from offers to encourage offline orders.

## 📂 Dataset Information
The dataset used in this project is `Zomato data .csv`.

The provided CSV file contains 148 rows and 7 columns.

### Dataset Columns

| Column Name | Description |
|---|---|
| `name` | Name of the restaurant |
| `online_order` | Whether online ordering is available |
| `book_table` | Whether table booking is available |
| `rate` | Restaurant rating |
| `votes` | Number of customer votes |
| `approx_cost(for two people)` | Approximate cost for two people |
| `listed_in(type)` | Restaurant category or type |

## ❓ Business Questions

This project follows the questions provided in the project guide.

1. **Restaurant Preferences:** What type of restaurant do the majority of customers order from?
2. **Customer Votes:** How many votes has each type of restaurant received from customers?
3. **Restaurant Ratings:** What ratings have the majority of restaurants received?
4. **Customer Spending:** What is the average spending per order for couples who order food online?
5. **Online vs Offline:** Which mode has received the maximum rating?
6. **Offline Order Promotions:** Which type of restaurant receives more offline orders and could be offered special promotions?

**Note:** The supplied CSV contains approximate cost for two people and online-order availability. It does not include an explicit couples/customer-type column or a separate order-count column. Therefore, some questions may require assumptions, additional data, or a clearly defined method of analysis.
